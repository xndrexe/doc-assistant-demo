# Описание для портфолио

Название: ИИ-помощник по документам компании в Telegram

Бот отвечает на вопросы сотрудников и клиентов по договорам, регламентам, инструкциям и прайсам. Вопрос пишут своими словами — бот находит нужный пункт и отвечает коротко, со ссылкой на документ и страницу. Если в документах ответа нет, так и говорит, а не выдумывает. Понимает PDF, Word и текст; новый документ администратор присылает прямо в бот, и он сразу ищется.

Модель подключается любая с API в формате OpenAI: бесплатные модели OpenRouter и Groq, OpenAI, YandexGPT, своя модель на сервере. Сменить модель — одна строка в настройках. Поиск по документам работает на месте, в модель уходят только несколько самых подходящих фрагментов — ответы быстрые и дешёвые.

Проверено: живой прогон на выдуманных документах сервисного центра с бесплатной моделью; бот — вживую в Telegram на тестовом боте и на тестах через настоящий диспетчер aiogram.

Стек: Python, aiogram, pypdf, python-docx.
